# PersonalAssistant test prompts

Run these in a private test channel after the Switch room is connected.

1. `@PersonalAssistant Help me plan a 90-minute study session for algebra.`
2. `@PersonalAssistant Turn these priorities into a realistic plan: finish my assignment, revise one chapter, and organize my notes.`
3. `@PersonalAssistant Explain APIs using a simple real-world example.`
4. `@PersonalAssistant Draft a polite message asking my teammate for a project update.`
5. `@PersonalAssistant Summarize this discussion into decisions, action items, and open questions.`
6. `@PersonalAssistant Break the goal 'build a portfolio website' into beginner-friendly tasks.`

Expected behaviour: clear plans, plain-language explanations, usable drafts, and honest statements about unavailable integrations. It must not claim to create actual reminders or calendar events.
